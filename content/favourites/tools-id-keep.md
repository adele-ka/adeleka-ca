1. **google workspace:** while i may hate on gemini, workspace is what i wish microsoft would have done with m365
2. **claude.ai:** easy to set up and use, great documentation (when you remember to ask) and easy file/project browsing
3. **canva:** some designers might hate on it but it has literally lowered the barrier to entry for people to get into graphic design
4. **figma:** it's kind of the web/app design gold standard
5. **whimsical:** if you need a place to start and put together ideas, draw diagrams, sticky notes or create mind maps, this is the place to go
6. **confluence:** imo the best technical documentation software, i hold it as a standard to my normal day-to-day note taking apps which really don't compare
